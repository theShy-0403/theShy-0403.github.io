# 郑经人 · 幻想手记

个人博客，采用二次元星空主题，包含动态流星、入场动画、音乐播放器、文章搜索、分类、归档和明暗主题。

网站：https://theshy-0403.github.io/

## 更新内容

编辑 `posts.js` 中的 `BLOG_POSTS` 数组，替换示例文章。文章正文是 HTML，仅填写自己维护的可信内容。

页面入口为 `index.html`，网站为纯静态 HTML、CSS 和 JavaScript，不需要 ChatGPT 登录，也不需要服务器或数据库。

## 发布

GitHub 仓库 Settings → Pages，选择 Deploy from a branch，分支 `main`、目录 `/ (root)`。

更新仓库中的网页文件后，GitHub Pages 会自动重新发布。

## 音乐

默认歌曲为王贰浪《把回忆拼好给你》，使用网易云公开播放地址，不托管歌曲音频。进入页面时尝试播放；浏览器拦截时，首次点击页面即可播放。音源可用性取决于网易云。
